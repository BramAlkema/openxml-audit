# Open-source DOCX round-trip corpus

This manifest selects deterministic DOCX fixtures whose source generator and
license are known. It does not copy or relabel arbitrary downloadable Office
files.

The first two documents are generated by TokenMoulds' MIT-licensed emitter API
and already live under `data/corpus/tokenmoulds_v0.7.2/word/`. Spec 028 records
the generation procedure and the bounded conversion from template content type
to document content type. They are corpus inputs only; the EuroOffice and
Google oracle implementations have no runtime relationship with TokenMoulds.

Run both live editors and the differential comparison with:

```bash
python -m openxml_audit.oracle docx-paired \
  data/corpus/tokenmoulds_v0.7.2/word/acme-us.docx \
  --output build/oracle/acme-us-paired.json
```

The paired command refuses to start EuroOffice unless all Google staging
configuration is present, so a missing Google subject or folder cannot leave a
one-sided live run.
